About Me

Hi, I'm Talha 👋

We test small kitchen tools for small families.

I'm a developer from Canada, currently learning web development by building real projects and shipping them to the internet. Foodiano World is my learning playground — a place where I practice HTML, CSS, and JavaScript, experiment with deployment tools like GitHub and Vercel, and write about what I learn along the way.

My approach is simple: build in public, finish small projects instead of dreaming about big ones, and share honest notes about the process — including the business side, like how websites earn money through advertising and affiliate programs.

What I'm Learning

  • Frontend: HTML, CSS, JavaScript — responsive design and interactivity
  • Deployment: Git version control, GitHub, and Vercel continuous deployment
  • Monetization: Google AdSense, affiliate marketing, and honest expectations about online earning

Why This Site Exists

Foodiano World started as a demo dashboard and grew into a small blog about web development and monetization. Every article here is written from my own experience building the site — no copied content, no shortcuts. If you're learning web development too, I hope my notes save you some time.

Want to say hi or ask a question? Head to the contact page — I read every message.
